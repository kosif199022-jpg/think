# KOSIF Think

Unified orchestration and execution platform for KOSIF.

## Goal
KOSIF Think is the single surface for reasoning, computer control, browser automation, Jev decision routing, WhatsApp actions, verification, recovery, memory, and tool orchestration.

## Unified capability model
- Think / Council / Deep reasoning
- KOSIF Computer capabilities
- Jev-Browser stable action graph and bounded decision routing
- WhatsApp messaging and file workflows
- Browser control via persistent Playwright/CDP and DevTools
- Windows UI Automation, dialogs, app control, screen-state verification
- Memory, tracing, cancellation, recovery and verification

## Architecture principle
Think plans and routes. Deterministic tools execute. Jev resolves bounded ambiguity. Every consequential action is revalidated and every completion claim requires observable verification.
